El despliegue no se lanza desde aquí a propósito: un botón que ejecute comandos en el servidor sería el punto más delicado de toda la instalación. Se hace desde tu equipo, donde ya tienes las llaves:

Web: flutter build web --wasm --release --base-href=/app/ --no-web-resources-cdn --dart-define=SUPABASE_URL=https://glint.yanes.xyz --dart-define=SUPABASE_ANON_KEY=… y después dart run deploy/armar_sitio.dart + rsync -avz --delete build/site/ jonny@192.168.1.9:~/glint/web/

App: flutter build apk --release --dart-define=…, luego dart run deploy/armar_sitio.dart recoge el APK y lo publica en /descargas/.
